## 列表推导式语法
列表推导式（List Comprehension） 是 Python 中一种简洁、表达力强的语法，用于从一个可迭代对象（iterable）生成新的列表。它通常可以将传统的 for 循环 + 列表追加操作浓缩为一行代码，同时保持较高的可读性。

**基本语法结构**
```python
[表达式 for 变量 in 可迭代对象 if 条件]
```
各部分含义如下：

|组成部分|是否必须|说明|
|---|---|---|
|表达式|必须|对每个元素执行的计算或变换，结果成为新列表的元素|
|for 变量|必须|循环变量，依次绑定可迭代对象中的每个元素|
|in 可迭代对象|必须|任何可迭代对象（列表、元组、集合、字典、生成器、range、字符串等）|
|if 条件|可选|过滤条件，只有当条件为 True 时，该元素对应的“表达式”结果才会被保留|
**示例**
最简单形式（无过滤）
```python
# 传统写法
squares = []
for x in range(10):
    squares.append(x ** 2)

# 列表推导式
squares = [x ** 2 for x in range(10)]
# 结果: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```
带条件过滤
```python
# 只保留偶数的平方
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
# 结果: [0, 4, 16, 36, 64]
```
